=============== Docker:
Rabbit MQ

Xoa container cu
docker rm -f rabbitmq

Chạy lại bằng câu lệnh chuẩn này (Mở thêm cổng 61613 và 15674 cho WebSTOMP):
docker run -d --name rabbitmq -p 5672:5672 -p 15672:15672 -p 61613:61613 -p 15674:15674 rabbitmq:3-management

Bật plugin STOMP bên trong Docker:
docker exec -it rabbitmq rabbitmq-plugins enable rabbitmq_stomp rabbitmq_web_stomp

Restart Docker
docker restart rabbitmq

Kiem tra cong 61613 da mo chua
1. Bạn mở thanh tìm kiếm Windows, gõ chữ PowerShell và mở nó lên.
2. Dán chính xác câu lệnh sau vào và nhấn Enter:powershell
Test-NetConnection localhost -Port 61613
